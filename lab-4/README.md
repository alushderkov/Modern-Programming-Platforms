# Лабораторная 4

Игра на захват клеток. Несколько человек играют в одном поле, ходы уходят по WebSocket.

Запуск:

```
npm install
npm start
```

Страница: http://localhost:3000

Две вкладки - два игрока. Правила в RULES.md.

Сервер - `server.js`, браузер - `public/`. Состояние пишется в `data/game.json`.
